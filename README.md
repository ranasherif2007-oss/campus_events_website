# 🎓 Campus Events Guide Website

A responsive, multi-page web platform designed for students at Zewail City of Science and Technology to explore campus events, check event schedules, view event details, and register.

---

## 🌟 Features

- **Integrated Event Journey:** Consistently features a core sample event across all 5 pages.
- **100% Semantic HTML5:** Structured using clean, accessible semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Responsive Layouts:** Built using CSS Grid for multi-column event cards and Flexbox for headers, navigation, and alignment[cite: 1, 3, 37].
- **CSS-Only Dark Mode:** Toggle between Light and Dark mode using pure CSS `:has()` relational selectors without any JavaScript[cite: 1, 3, 37].
- **Complete Registration & Review Forms:** Includes all 13 mandatory HTML5 form controls with native browser validation.
- **Media Controls:** Features interactive HTML5 video preview components.
